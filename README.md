# Skhoron-2FA

A fully local TOTP authenticator for Android. No server, no account, and no "INTERNET" permission in the manifest. After being added, the secret remains only in Android Keystore as an HMAC key.

Components

Folder| Contents| Verification Status
"core/reference-python"| HOTP/TOTP, "otpauth://" parsing, Google Authenticator import, encrypted export, CLI| 34 tests, runnable
"core/jvm"| The same core in Java with no dependencies (used by the Android code)| 524 checks, runnable
"core/test-vectors"| Shared vectors for both implementations (generated by "tools/gen_test_vectors.py")| Used by both test suites
"android"| Keystore, BiometricPrompt, FLAG_SECURE, minimal screen| Not built or run (no Android SDK or Kotlin); checked against Android documentation; static check in "tools/static_check_android.py"
".github/workflows"| Unsigned APK build and core checks| Not run; description and risks in "docs/BUILD.md"
"docs"| Architecture, export format, comparison with other apps, APK build| 

The Android screen currently supports: adding an entry via "otpauth://totp/..." (as text), displaying codes with a countdown after signing in with biometrics or a PIN, deleting an entry with a long press, offering an encrypted backup immediately after adding an entry, and restoring entries from such a file.
It does not support: QR scanning, HOTP, Google import, search, or the "EVERY_USE" mode in the interface.

Running Checks

cd core/reference-python && python3 -m unittest discover -s tests      # requires cryptography >= 46
java tools/run-jvm-tests.java                                          # requires JDK 17+; run from the project root

APK build: "docs/BUILD.md" (GitHub Actions produces an unsigned APK; signing must be done locally on your machine).

Code for a single entry without installation:

cd core/reference-python
python3 -m skhoron2fa code "otpauth://totp/RFC:test?secret=GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ&digits=8" --time 59
