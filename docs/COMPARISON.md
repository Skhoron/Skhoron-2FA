# Что у других и что сделано здесь

Источники: описания Aegis (README, обзор LinuxLinks), 2FAS (обзор LinuxLinks, App Store, отзывы на AlternativeTo),
сравнение на сайте Ente, обсуждение Proton Authenticator на форуме Techlore, описание расширения exte
в Chrome Web Store. Это описания и отзывы, а не проверка самих приложений.

| Что у других | У кого | Здесь сейчас |
|---|---|---|
| Шифрованное хранилище AES-256-GCM, разблокировка паролем или биометрией | Aegis | Секреты не в файле, а в Keystore-ключах; биометрия или PIN устройства |
| Шифрованный экспорт с паролем | Aegis, 2FAS, exte (PBKDF2 + AES-GCM) | Argon2id + AES-256-GCM. На Android предлагается при добавлении аккаунта, восстановление из файла есть; на устройстве не запускалось |
| Автобэкап в выбранное место | Aegis | Нет |
| Импорт из других приложений | Aegis (много), 2FAS (несколько) | Только Google Authenticator, в `core/reference-python` |
| Импорт Google «Transfer accounts» | exte | Есть (`migration.py`), проверен на стороннем образце и синтетических данных; на реальном QR из вашего Google Authenticator не проверялся |
| Импорт без дублей | exte | В `core` есть (`merge_entries`). На Android сравнение по издателю, аккаунту, алгоритму, цифрам и периоду, секрет не сравнивается: его негде прочитать |
| Защита от скриншотов | Aegis | `FLAG_SECURE` |
| Скрытие кодов до нажатия | Aegis | Нет |
| Работа без сети и аккаунта | 2FAS, exte (расширение без сетевого разрешения) | В манифесте нет `INTERNET` |
| Показ следующего кода в последние секунды | отзыв пользователя о 2FAS | Нет |
| Расширение для браузера | 2FAS | Нет |
| Синхронизация между устройствами | Ente Auth, Proton Authenticator, 2FAS (Google Drive) | Нет: требует сервера или облака |

Жалобы из отзывов, которые учтены в формате: пользователь 2FAS писал, что файл `.2fas` не открыть в других
приложениях; в обсуждении Proton Authenticator пользователь сообщал, что он не читает зашифрованный экспорт Ente.
Здесь формат документирован (`EXPORT_FORMAT.md`), и есть выгрузка в обычный список `otpauth://`.

В прочитанных описаниях не упоминается, чтобы секрет оставался внутри аппаратного хранилища и приложение
вообще не могло его прочитать. Здесь так сделано, и цена этого описана в `DESIGN.md` (нельзя повторно выгрузить секрет).
