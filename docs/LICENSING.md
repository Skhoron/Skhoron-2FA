# Лицензия

Проект распространяется под Apache License 2.0.

- `LICENSE` - полный текст. Файл побайтно совпадает с копией лицензии в дистрибутиве Debian
  (`/usr/share/common-licenses/Apache-2.0`) и с `LICENSE` пакета absl-py, sha256
  `cfc7749b96f63bd31c3c42b5c471bf756814053e847c10f3eb003417bc523d30`. Хеш зашит в
  `tools/static_check_android.py`, и проверка падает, если текст изменён.
- `NOTICE` - строка авторских прав: `Copyright 2026 Skhoron contributors`. Если нужно другое имя
  (своё или организации), поменяйте её и только её: в `LICENSE` ничего не вписывается.
- Каждый исходный файл (`.py`, `.java`, `.kt`, `.kts`, `.sh`, `.yml`) начинается со строки
  `SPDX-License-Identifier: Apache-2.0`; наличие проверяется тем же скриптом.

## Зависимости

| Что | Где | Лицензия |
|---|---|---|
| androidx.appcompat, androidx.biometric, Kotlin stdlib | входят в APK | Apache 2.0 |
| cryptography (Python) | только тесты и эталон, в APK не входит | Apache 2.0 или BSD |
| Gradle, Android Gradle Plugin, Android SDK | только сборка, в APK не входят | не распространяются с проектом |

При раздаче APK тексты лицензий и NOTICE встроенных библиотек полагается показывать пользователю.
Экрана «Лицензии» в приложении пока нет.

## Совместимость

Apache 2.0 совместима с GPLv3 (ваш код можно включить в проект под GPLv3), но не с GPLv2-only.
Закрытые форки лицензия не запрещает. Это справка, а не юридическая консультация.
